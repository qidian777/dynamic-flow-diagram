# 交付前验收清单

逐条过，每条都要有明确结论。**第 0 条不过，后面全都别做。**

## 0. 事实核对
- [ ] 节点数量与原始图一致（少一个就是漏了）
- [ ] 每条连线的分支标签（是/否、外协/自制）都还原了
- [ ] 原文里所有「流程说明」段落都有归处
- [ ] 与原文冲突的地方（编号跳号、文字与图形不一致）**主动告知用户**，不要自己悄悄改

## 1. 图形
- [ ] 起止用胶囊、作业用矩形、判断用菱形、数据用平行四边形、系统用圆柱、子流程用双线矩形
- [ ] 没有自创形状
- [ ] 菱形内文字不超过 3 行，没有溢出
- [ ] 图例与实际使用的图形一致

## 2. 布局
- [ ] 同列节点 x 坐标完全对齐
- [ ] 连线不穿过任何节点
- [ ] 连线标签不与节点、其他连线重叠
- [ ] 泳道分隔线与泳道标题条左右边界精确对齐
- [ ] 底部节点不被图例/提示条遮挡

## 3. 浮层（最高频问题区）
- [ ] 悬停气泡在节点左右两侧，不在上下
- [ ] 气泡不覆盖任何其他节点
- [ ] 气泡在窗口边缘不被裁切
- [ ] 侧边清单默认收起（窄窗口）
- [ ] 没有多余的缩略图/迷你地图挡画布
- [ ] 抽屉打开时画布内容不被压扁

## 4. 交互
- [ ] 每个阶段标签点击后，只留该阶段节点可见，布局重新居中
- [ ] 按岗位切换后，非该岗位节点淡出
- [ ] 悬停 → 气泡；点击 → 抽屉；抽屉里的上下游可跳转
- [ ] 演示可以从任意阶段启动，随时能停，停止后回到全图
- [ ] 缩放/平移/拖拽节点都正常，拖完后连线跟随
- [ ] 「适应窗口」后内容不被顶部冻结条压住

## 5. 内容
- [ ] 每个节点都有：编号、文本、岗位、说明
- [ ] 说明文字是业务语言，不是"执行该步骤"这类废话
- [ ] 岗位名与用户组织的实际叫法一致（不是"用户""操作员"这种泛称）

## 6. 技术
- [ ] 单文件，双击可开，断网可用
- [ ] 控制台无报错
- [ ] 1200×800 与 1600×900 两个尺寸下都正常
- [ ] 体积 < 200 KB

## 截图自查（必做）

```bash
# 依赖：npm i playwright --no-save
node scripts/shot.js <html路径>
```

产出 4 张图：初始全图 / 单阶段 / 悬停气泡 / 抽屉打开。逐张看图确认上述条目，**不要只看控制台输出**。

看图时的固定问法：
1. 有没有任何元素压住了别的元素？
2. 有没有文字超出边框或被裁掉？
3. 有没有两块内容看起来"应该对齐但没对齐"？
